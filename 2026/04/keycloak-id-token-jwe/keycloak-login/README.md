This is a [Next.js](https://nextjs.org) project with [Better Auth](https://better-auth.com) and Keycloak login.

## Getting Started

## Environment variables

Create a `.env.local` file with:

```bash
BETTER_AUTH_URL=http://localhost:3000
NEXT_PUBLIC_BETTER_AUTH_URL=http://localhost:3000
KEYCLOAK_CLIENT_ID=your-client-id
KEYCLOAK_CLIENT_SECRET=your-client-secret
KEYCLOAK_ISSUER=https://your-keycloak-host/realms/your-realm
```

`KEYCLOAK_ISSUER` must include the realm path.

## Getting started

Run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) to use the login page.
